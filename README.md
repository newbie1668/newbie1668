## 🧪 Selected projects

### HS code review assistant — powered by Jev
**AI workflow prototype · Next.js / TypeScript / TypeSafe**

Helps a reviewer turn shipping documents into draft HS6 classifications. Suggestions follow a pinned HS taxonomy; the interface shows decision traces, flags exceptions, and supports human confirmation and draft export. Customs filing stays blocked.

**Product focus:** make uncertain AI output inspectable and keep consequential decisions with the reviewer.

[Source & local demo instructions](https://github.com/newbie1668/jev-hs-assistant)

### Operation Shade — creator inbox triage
**Team Jano hackathon project · Jev / TypeSafe**

A team project I helped build to reduce repetitive creator DMs while preserving the creator's judgment. Jev classifies messages into four lanes; replies are assembled from the creator's existing playbook, with uncertain or personal messages escalated for review. Approved wording can be reused across matching replies.

**Product focus:** reduce repetitive work while keeping the creator in control of her voice. The prototype uses a mostly synthetic inbox and has no automatic sending or live Instagram/TikTok integration.

[Watch the hackathon demo](https://www.loom.com/share/2ac289a9748d4fb6aeddaf56527aca46) · [Team repository](https://github.com/KaushikKC/OperationShade) · [Try the console](https://operation-shade-jano.vercel.app/)

### M/ETHANE — voice-first incident reporting
**Unofficial hackathon prototype · Python / React / local speech recognition / Ollama**

Turns an officer's spoken account into the seven JESIP M/ETHANE fields. The interface distinguishes estimated, inferred, and confirmed information, and asks the officer to review the report. Speech processing runs locally.

**Product focus:** reduce form-filling effort while preserving the source and certainty of each field. Demo only; no live emergency-system integration.

[90-second walkthrough](https://github.com/newbie1668/frontline-london-hackathon#90-second-walkthrough) · [Source & local demo instructions](https://github.com/newbie1668/frontline-london-hackathon)

### My Wardrobe — Wada Look Builder
**Open-source fork · JavaScript / AI image generation**

My fork adds colour-guided outfit building to an existing wardrobe app: start with a garment, choose practical pairings from clothes you own, save the look, and optionally generate a modeled preview with a fidelity check.

**Product focus:** turn a clothing catalogue into a useful daily decision tool.

[Source & screenshots](https://github.com/newbie1668/mywardrobe)

## How I work

- **Frame the problem:** understand the user's decision, constraints, and intended outcome.
- **Make the tradeoff concrete:** build a small working slice that people can try and critique.
- **Design for trust:** show uncertainty, support review, and provide useful fallback behaviour.
- **Build for reuse:** leave clear setup instructions, product context, and a handoff others can work with.

My hands-on toolkit includes **Claude Code, Codex, TypeScript, React, Next.js, Mapbox, and Airtable**. These projects show how I combine product judgment with AI-assisted building.
